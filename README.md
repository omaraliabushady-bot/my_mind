# My Mind | دِماغ مبرمِج 🧠✨
### نظام الإنتاجية والتركيز الفائق لمطوري البرمجيات (Cloud-Connected Productivity System)

تطبيق ويب عصري متكامل، فائق السرعة، ومصمم بجمالية الزجاج المظلم (**Dark Glassmorphism**) لتعزيز التركيز، القضاء على التسويف والمماطلة، ومزامنة إنجازاتك اليومية عبر السحابة مع قاعدة بيانات **Supabase** ونظام مصادقة المستخدمين (**Authentication**)، ومجهز للرفع الفوري على **Vercel**.

---

## 🌟 الميزات الجديدة والمحدثة (Latest Updates)

### 1. بداية نظيفة بدون أي بيانات وهمية (100% Clean Zero Slate)
- تم تنظيف التطبيق بالكامل من أي مهام أو مشاريع تجريبية مسبقة.
- يبدأ أي مستخدم جديد من الصفر تماماً:
  - **0 مهام**
  - **0 مشاريع**
  - **0 نقاط خبرة (0 XP)** والمستوى الأول (*مبتدئ التركيز / Novice Thinker*)
  - **0 أيام سلسلة إنجاز**
  - كافة الأوسمة مقفلة حتى يتم تحقيقها فعلياً عبر استخدام التطبيق.

### 2. نظام تسجيل الدخول والحسابات (Authentication & Sessions)
- واجهة زجاجية داكنة فخمة متناسقة مع ألوان التطبيق لتسجيل الدخول وإنشاء الحسابات (**Login / Register**).
- التسجيل عبر **البريد الإلكتروني وكلمة المرور**.
- **حفظ الجلسة الدائم (Stay Logged In)**: لن تضطر لإعادة كتابة كلمة المرور في كل مرة تفتح التطبيق فيها من هاتفك المحمول أو متصفحك.
- زر **تسجيل الخروج (Log Out)** وقائمة المستخدم مع إمكانية المزامنة اليدوية الفورية.

### 3. ربط قاعدة البيانات السحابية (Supabase Database Integration)
- ربط مع **Supabase (PostgreSQL)** لحفظ ومزامنة:
  - المهام والمهام الفرعية (`tasks`)
  - المشاريع والأهداف الأسبوعية (`projects`)
  - جلسات البومودورو والتركيز (`pomodoro_sessions`)
  - المستويات ونقاط XP والإحصائيات والأوسمة (`profiles`)
- تفعيل سياسات الأمان على مستوى الصفوف (**Row Level Security - RLS**) بحيث تكون بيانات كل مستخدم معزولة ومحمية بالكامل بواسطة `user_id = auth.uid()`.
- ملف مخطط قاعدة البيانات الجاهز للتشغيل بضغطة زر متوفر في:
  [`supabase/schema.sql`](./supabase/schema.sql)

### 4. التجهيز الكامل للرفع على Vercel (Deployment Ready)
- ملف [`vercel.json`](./vercel.json) المجهز لمعالجة توجيه مسارات SPA وإعدادات الكاش والترويسات الأمنية.
- ملفات البيئة [`.env.example`](./.env.example) و [`.env`](./.env) جاهزة لإضافة مفاتيح الربط بضغطة زر.

## 🛠️ كيفية ربط قاعدة بيانات Supabase خطوة بخطوة

1. أنشئ مشروعاً مجانياً على [Supabase](https://supabase.com).
2. من لوحة تحكم Supabase، توجه إلى **SQL Editor**، وافتح الملف [`supabase/schema.sql`](./supabase/schema.sql) وانسخ محتواه والصقه ثم اضغط **Run**.
3. توجه إلى **Project Settings -> API** وانسخ:
   - `Project URL`
   - `anon public key`
4. الصق القيم داخل ملف `.env`:
   ```env
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
   ```
5. سيتعرف التطبيق فوراً على المفاتيح ويتحول إلى وضع المزامنة السحابية الحي!

---

## 🚀 كيفية الرفع على Vercel بضغطة زر

1. ارفع المشروع إلى حسابك على **GitHub**.
2. توجه إلى موقع [Vercel](https://vercel.com) واختر **Add New Project** وحدد مستودع المشروع.
3. في قسم **Environment Variables** على Vercel، أضف المتغيرين التاليين:
   - `VITE_SUPABASE_URL` = رابط مشروع Supabase
   - `VITE_SUPABASE_ANON_KEY` = المفتاح العام anon
4. اضغط **Deploy**! سيتولى Vercel البناء والنشر تلقائياً خلال ثوانٍ معدودة.
